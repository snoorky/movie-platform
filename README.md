# Movie Catalog with API Integration

This project is a movie catalog application that consumes data from a public API, displaying a list of popular movies, allowing users to search for specific titles, and providing detailed information on each movie when clicked.

<img src="/public/screenshot.png" alt="Application screenshot" />

## 📚 Technologies

The project was developed using the following technologies:

- ⚡️ ReactJS
- 🎨 TailwindCSS
- 🌐 Axios
- 🔄 React Router

## 💻 Project

The project offers the following features:

1. **Popular Movies List**: Displays a list of popular movies fetched from a public API.
2. **Search Functionality**: Includes a search bar to find movies by name.
3. **Movie Details Page**: Clicking on a movie shows detailed information about the selected title.
4. **Responsive Design**: Ensures a great user experience on both mobile and desktop devices.
